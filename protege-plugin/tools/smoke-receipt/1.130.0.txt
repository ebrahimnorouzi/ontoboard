WHAT THIS RELEASE ADDS

- Project > History...: every release kept in releases/, what each holds and what changed from
  one to the next, term by term; any two compared; any release opened in a window of its own.
- Find terms in another ontology...: load an ontology from a web address or a file, search its
  labels, tick terms, import them - no IRIs needed.
- Start here: the guide...: the steps from an idea to a released ontology, ticked against the
  open project, each with what it does, why, and a button that does it. Also on the empty board.
- Add all frames each design pattern an ontology imports or has merged in, in a row along the
  top of the board. A pinch on a Mac trackpad zooms.
- A pattern imported from the library records the pattern's IRI, not this machine's path, and
  is not declared as an ODK product; Refresh imports leaves it alone. A search in the library
  finds patterns that are not among the suggestions.
