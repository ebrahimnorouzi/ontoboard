IMPORT MODULES ARE REBUILDABLE AGAIN

An ODK project does not commit an import module as a finished artefact. It commits the list of
terms it wants - imports/iao_terms.txt - and regenerates the module from it whenever the upstream
ontology moves. That is what makes `make refresh-imports` mean anything, and it is the difference
between a repository somebody else can build and one carrying a binary blob nobody dares touch.

This plugin wrote the module and not the list. ROBOT > Import terms... would extract
imports/iao_import.owl, add the import statement and write the catalog entry - all correct, all
useful - and the next person to clone the repository had a module they could not reproduce, could
not extend, and could not tell had gone stale. The one file that makes the ODK imports/ layout
work was the one file missing.

  Import terms... now writes imports/<name>_terms.txt beside the module, recording the terms and
  the source they came from. Sorted and deduplicated, because extraction order is not stable and a
  list that reshuffles on every rebuild makes every refresh look like a change - after which
  nobody reads the diffs.

  Project > Refresh imports... answers both halves. By default it only reports: which imports have
  a term list, which have a module, which record their source. That audit needs no network and is
  the question worth asking about a repository you have just cloned - can it be rebuilt at all?
  Turning on the rebuild re-extracts each module from its recorded source, which is the in-Protege
  equivalent of ODK's refresh-imports.

A project built with an earlier OntoBoard will report imports that cannot be rebuilt. That is
correct and deliberate: those modules really cannot be, and re-running Import terms... for each
writes the missing list. The audit is meant to surface exactly this.

The rebuild reports a term that is in the list but no longer in the upstream ontology, rather than
dropping it. An upstream obsoletion is precisely the thing a refresh exists to discover, and a
module that silently comes back three terms smaller is how somebody ships a release missing a
definition.
