OntoBoard 1.143.0 - host smoke receipt

The rest of the 1.141.0 review is fixed, each with a test that failed first:
- A role saved in the project is redacted for every key OntoBoard knows, not only for text
  shaped like a key. A remembered key typed into a role had been written to
  assistant/roles/ontology-expert.md, which is committed with the project. Groq (gsk_), xAI
  (xai-) and Hugging Face (hf_) keys are now key-shaped too.
- In the repair benchmark, an answer the reasoner cannot handle is that row's error. The run
  goes on and the answer is kept, in run and in score.
- When an axiom cannot be read either way, the card names the name that is missing, not a word
  of a label that exists.
- Only classes, properties and individuals become chips from a sentence: an annotation property,
  or a labelled IRI that is not a term, no longer hides a class (in MWO, dcterms:license hid
  'license'). No shipped case changed.
- A safety check that runs out of time is the row's error, not a silent "unsafe".
- A run into a folder that holds an earlier run keeps that run's files as
  replies.previous.jsonl, results.previous.csv and summary.previous.md.
