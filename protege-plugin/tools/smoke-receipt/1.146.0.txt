OntoBoard 1.146.0 - host smoke receipt

The fresh review of 1.145.0 is acted on, and so are two privacy gaps left from 1.144.0. Four
reviewers read the code, one area each. An independent checker reproduced each serious finding
and tried to refute it; the findings beyond the checkers were reproduced by their own failing
tests. Four agents made the fixes, each test-first in its own copy of the tree, on files only it
owned. Each diff was then read line by line before it was merged. Each change has a test that
failed first:
- Saved conversations:
  - What counts is how things stood when a question was asked. A question asked while nothing was
    saved, while private or undecided, or before Release never reaches conversations/released/,
    even if the switch or the choice changes during its answer. A question that could not be
    saved because the rules failed counts the same.
  - The private file is always the whole conversation. Decisions, reasoner checks and an answer
    in flight when a conversation is released reach it.
  - Notices are true. One is given only after its file was written. When a conversation with a
    released part goes private, the notice names that part's file, which git still sees. A rules
    problem names the file that is wrong, says that git may see earlier conversations, and is
    said once.
  - The clone's exclude rules hold for a folder with brackets in its name and for a project
    opened through a junction. A project reached through a junction has one release choice, not
    two.
- Keys:
  - A key typed or remembered goes only to the host it was given for. A preset picked over a
    saved connection starts a new one. Test connection and Fetch the list do not send a stored
    key to another address. Saving a connection on another host without a new key forgets the
    old one.
  - The benchmark never prints a models file's text: a JSON error gives only the line and
    column, and every line on the error stream is redacted. It refuses a key under any key-like
    field name at any depth, in an address, or in place of a variable's name, and it shows a
    variable's name only when it is an upper-case name.
  - Redaction no longer eats ordinary text. An address ends at a quote, comma, bracket or space,
    and a hyphenated word such as sk-learn-compatible-... is no key.
- Settings and the assistant:
  - The role line follows the ontology's first save or a Save As while Settings stays open.
    Save, Reset, Delete and New role write nothing while the line names an old place.
  - A role text typed and not saved survives a reload.
  - After Protege is maximised or restored, the context chips are measured at the new width.
- Benchmark: an answer that offers more than one card - an alternative axiom or definition, a
  removal, a comment - no longer passes. Before, only the first block was scored, so the order
  of the blocks decided. results.csv has a new last column, proposals.
