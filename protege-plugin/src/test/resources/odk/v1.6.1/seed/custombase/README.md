# Shop ontology

Description: An ontology of a shop, with its own namespace

More information can be found at http://obofoundry.org/ontology/shop

## Versions

### Stable release versions

The latest version of the ontology can always be found at:

https://w3id.org/shop/shop.owl

(note this will not show up until the request has been approved by obofoundry.org)

### Editors' version

Editors of this ontology should use the edit version, [src/ontology/shop-edit.owl](src/ontology/shop-edit.owl)
