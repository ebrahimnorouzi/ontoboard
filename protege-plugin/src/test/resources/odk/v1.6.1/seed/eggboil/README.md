# Test kitchen ontology

Description: Application ontology for boiling eggs in a test kitchen

More information can be found at http://obofoundry.org/ontology/eggboil

## Versions

### Stable release versions

The latest version of the ontology can always be found at:

https://example.org/eggboil/eggboil.owl

(note this will not show up until the request has been approved by obofoundry.org)

### Editors' version

Editors of this ontology should use the edit version, [src/ontology/eggboil-edit.owl](src/ontology/eggboil-edit.owl)
