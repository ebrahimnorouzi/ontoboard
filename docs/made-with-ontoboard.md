# Made with OntoBoard

Ontologies built with OntoBoard. Each one is a repository: clone it, open its edit file in
Protégé, and every step that made it is a menu action you can repeat.

<div class="ob-grid" markdown>

<div class="ob-card" markdown>
### :material-pizza: Pizza ontology
Pizzas, their bases, toppings, spiciness and prices, from three ontology design patterns
(Componency, Classification, Price), following eXtreme Design. Five releases.

[Repository](https://github.com/ebrahimnorouzi/pizza-ontology) ·
[Try it](examples/pizza.md)
</div>

<div class="ob-card" markdown>
### :material-table-large: Pizza BFO
The same pizzas on BFO 2020, with BFO and NFDIcore patterns and a knowledge graph of bakings built from
nine ROBOT templates. Six releases, the last one the graph's.

[Repository](https://github.com/ebrahimnorouzi/pizza-bfo) ·
[Try it](examples/pizza-bfo.md)

## Add yours

Built an ontology with OntoBoard? [Open an issue](https://github.com/ebrahimnorouzi/ontoboard/issues/new)
titled *Made with OntoBoard: your ontology's name*, with a link to its repository and a sentence
about what it covers, and it will be listed here.
